# Library Management System -- Output Screenshots

## Execution Screenshots

The screenshots demonstrate the successful execution of the Library
Management System.

### Screenshot Sequence

1.  **View Library (Initial)**
    -   Displays all available books and journals.
2.  **Issue Book**
    -   Issues Book ID `101` successfully.
3.  **View Library After Issuing Book**
    -   Shows the book status as **Issued**.
4.  **Issue Journal**
    -   Issues Journal ID `201` successfully.
5.  **View Library After Issuing Journal**
    -   Displays both items with updated issue status.
6.  **Return Book**
    -   Returns Book ID `101` successfully.
7.  **View Library After Returning Book**
    -   Shows the returned book as **Available**.
8.  **Return Journal & Exit**
    -   Returns Journal ID `201` and exits the program successfully.
