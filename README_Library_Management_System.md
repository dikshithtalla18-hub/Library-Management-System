# Library Management System (C++)

## Project Description

A console-based Library Management System written in C++. It
demonstrates Object-Oriented Programming concepts including inheritance,
polymorphism, virtual functions, and dynamic memory management.

## Features

-   View Library
-   Issue Item
-   Return Item
-   Book and Journal classes
-   Inheritance
-   Polymorphism
-   Dynamic memory using pointers

## Technologies Used

-   C++
-   OOP
-   STL Vector

## Program Structure

-   Base class: `MediaItem`
-   Derived classes: `Book`, `Journal`
-   Collection: `vector<MediaItem*>`

## Menu

1.  View Library
2.  Issue Item
3.  Return Item
4.  Exit

## How to Compile and Run

``` bash
g++ library_management_system.cpp -o library_management_system
./library_management_system
```
